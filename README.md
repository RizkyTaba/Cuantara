# Cuantara

[![Versi terbaru](https://img.shields.io/github/v/release/RizkyTaba/Cuantara?label=versi&color=0f9d6b)](https://github.com/RizkyTaba/Cuantara/releases/latest)

Aplikasi manajemen keuangan pribadi untuk dipakai di HP. Data tersimpan di perangkat sendiri.

## Unduh (Android)

**[Unduh APK terbaru](https://github.com/RizkyTaba/Cuantara/releases/latest/download/Cuantara.apk)**

Versi sebelumnya ada di halaman [Releases](https://github.com/RizkyTaba/Cuantara/releases). Nomor versi tertera di nama rilis dan di aplikasi (tab Dompet, paling bawah).

Cara pasang: buka berkas APK yang diunduh, izinkan instal dari sumber ini, lalu pilih Instal. Peringatan Google Play Protect itu normal untuk aplikasi di luar Play Store.

## Fitur
- Catat pemasukan, pengeluaran, dan transfer antar dompet
- Anggaran bulanan dan target tabungan
- Kartu rasio tabungan dengan komentar bergaya Gen Z
- Transaksi berulang, kunci PIN, dan pengingat
- Ekspor laporan ke Excel (.xlsx)
- Cadangkan dan pulihkan data

## Catatan
- Setiap perubahan kode memicu pembuatan APK baru dengan nomor versi otomatis (1.0.N).
- Data tersimpan di perangkat (localStorage), tidak dikirim ke server mana pun.
